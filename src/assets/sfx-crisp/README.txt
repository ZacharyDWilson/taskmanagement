"Crisp UI" sound style. Drop the downloaded files here, named after the moment they play:

  press.mp3          every button press            <- "User Interface, Click, UI Buttons, Confirm, Menu"
  open.mp3           pop-ups and menus opening     <- "User Interface, Click, Software, Interface, Pop Up, Notification, Digital"
  close.mp3          closing / going back          <- "User Interface, Click, UI Buttons, Select, Previous"
  check.mp3          ticking a box, small toggles  <- "User Interface, Beep, Button Click, Plop, Short"
  info.mp3           small tips and toasts         <- "User Interface, Click, Button, Double Click, Fast, Phone Tap"
  notification.mp3   new mail / friend alerts      <- "User Interface, Alert, Notification, Email, Get"
  success.mp3        finished a task or session    <- "User Interface, Alert, Alerts, Notification 07"

.mp3 .wav .ogg .m4a all work. Any moment without a file uses the Minimal pack, and the style only
appears in Settings once at least one file is here.
